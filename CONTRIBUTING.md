# Contributing to AdocEditor Repository

Thanks for helping improve AdocEditor documentation and issue quality.

## What to submit

- **Bug reports**: Use `ISSUE_TEMPLATE/bug_report.md`
- **Feature requests**: Use `ISSUE_TEMPLATE/feature_request.md`
- **Usage questions**: Use `ISSUE_TEMPLATE/question.md`

This repository is docs/roadmap/issues only. Do not submit product source changes.

## Feature request format

Include:
- Summary
- User story (`As a ..., I want ..., so that ...`)
- Use cases
- Acceptance criteria
- Priority (P0/P1/P2)
- Proposed solution (optional)

## Bug report quality guidelines

Please provide:
- Clear steps to reproduce
- Expected vs actual behavior
- Environment (OS, browser, version)
- Logs/screenshots (redacted)
- Minimal reproducible example when possible

Never post secrets, private keys, or personal data in public issues.

## Triage process and SLA

- Maintainers triage issues weekly.
- Target first triage response: **within 7 days**.
- New issues are labeled `triage needed`.
- Priority can be set with `P0`, `P1`, `P2` labels.

## Label meaning (summary)

See [LABELS.md](./LABELS.md) for full label definitions.

## Privacy & security reporting

For sensitive or security-related reports, email: **security@adoceditor.com** (replace with maintainer address).
