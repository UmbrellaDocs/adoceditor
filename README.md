Issue tracker, roadmap, and documentation for AdocEditor.

- Product site: https://adoceditor.com/
- Product model: **closed-source; free for personal use**
- Repository scope: docs, public issue tracking, and roadmap planning only

## Report issues

Open an issue and use the relevant template:
- Bug: `ISSUE_TEMPLATE/bug_report.md`
- Feature: `ISSUE_TEMPLATE/feature_request.md`
- Question: `ISSUE_TEMPLATE/question.md`

Please remove or redact private data before posting.

## Request features

Open a **Feature request** issue with user story, use cases, and acceptance criteria.

## Contributing

PRs are accepted for repository documentation/process updates. For product behavior changes, open an issue first.

## Support & Security

For security-sensitive reports, do **not** open a public issue. See [SECURITY.md](./SECURITY.md).
